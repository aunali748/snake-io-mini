# Snake.io Mini 🐍

A short, fun snake.io / slither.io-style game in a single HTML file. Built by SAITAMA.

## Play

Just open `index.html` in your browser — no build step needed.

Or play it via GitHub Pages after pushing.

## Controls

- **Move:** mouse / arrow keys / WASD / touch
- **Boost:** hold click / space / touch

## Features

- Smooth slither.io-style movement
- 7 AI bot snakes
- Glowing food orbs, growth & boost mechanics
- Leaderboard, score HUD, game-over / restart
- World border + minimap-style grid

Enjoy! One punch, one snake. 👊
